# Hotel Booking API

## Description
REST API for managing hotel bookings, rooms, and users.

## Tech Stack
- .NET Web API
- SQL Server
- Entity Framework

## Features
- Create / update / delete bookings
- Manage rooms and availability
- Basic validation

## How to Run
1. Clone repo
2. Run `dotnet run`
3. Access API at http://localhost:xxxx

## Sample Endpoints
GET /api/bookings
POST /api/bookings
